# Summary

Referencia oficial de sintaxis Markdown, el formato usado por todos los archivos de `.ai/` y por esta misma bóveda de conocimiento.

# Explanation

Fuente: https://www.markdownguide.org/

Verificado 2026-07-24: cubre sintaxis básica ("Getting Started" y "Basic Syntax") y sintaxis extendida (tablas, bloques de código, etc.).

# Why it matters

Toda la documentación de Hermes —`.ai/*.md`, `README.md` y cada nota de esta bóveda— está escrita en Markdown; conocer la sintaxis extendida (tablas, checkboxes `- [ ]`) es necesario para mantener la consistencia de formato usada en, por ejemplo, [[Stack Tecnologico de Hermes]] o los índices de backlog.

# Best Practices

Usar sintaxis extendida de forma consistente en toda la bóveda (por ejemplo, siempre tablas para comparativas, siempre checkboxes para backlogs pendientes).

# Common Mistakes

Mezclar HTML crudo con Markdown cuando la sintaxis extendida ya cubre la necesidad (tablas, listas anidadas).
