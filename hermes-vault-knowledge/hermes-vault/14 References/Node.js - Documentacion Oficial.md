# Summary

Documentación oficial de Node.js, entorno de ejecución para el tooling del frontend de Hermes.

# Explanation

Fuente oficial: https://nodejs.org/docs/latest/api/

Node.js se usa como entorno de desarrollo/build para React + Vite; no forma parte del runtime de producción del backend en C++.

# Why it matters

Es una dependencia de desarrollo necesaria para construir el frontend de [[Sprint 8 - Frontend]].

# Best Practices

Fijar la versión de Node.js usada en el proyecto (por ejemplo, vía `.nvmrc`) para builds reproducibles.
