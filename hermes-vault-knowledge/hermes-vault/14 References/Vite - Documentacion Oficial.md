# Summary

Documentación oficial de Vite, la herramienta de build del frontend de Hermes.

# Explanation

Fuente oficial: https://vite.dev/guide/ (el dominio `vitejs.dev` listado en `.ai/OFFICIAL_SOURCES.md` redirige de forma permanente — 301 — a `vite.dev`; verificado 2026-07-24. Recomendado actualizar `.ai/OFFICIAL_SOURCES.md` con el dominio nuevo.)

Vite ofrece un servidor de desarrollo con Hot Module Replacement muy rápido sobre módulos ES nativos, y un bundler de producción (basado en Rolldown) para el proyecto React + TypeScript de Hermes. Se integra con React mediante su sistema de plantillas y plugins oficiales.
