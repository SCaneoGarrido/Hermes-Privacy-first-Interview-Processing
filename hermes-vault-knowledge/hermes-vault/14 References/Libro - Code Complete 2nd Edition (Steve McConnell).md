# Summary

Libro aprobado (Priority 3) sobre construcción de software, fundamento de las prácticas de calidad de código de Hermes.

# Explanation

*Code Complete, 2nd Edition*, de Steve McConnell. Disponible localmente en `docs/Libros/`.

Cubre prácticas de construcción de software a nivel de función, clase y módulo: nomenclatura, complejidad, testing, gestión de la deuda técnica. Se usa como referencia de apoyo para la [[Hermes Coding Standard]] y el principio [[Maintainability over Cleverness]].

No se reproduce contenido textual del libro; las notas derivadas son resúmenes y adaptaciones.

# Why it matters

Complementa las reglas concretas de `.ai/CODING_STANDARD.md` (Priority 1) con el razonamiento general de ingeniería de software detrás de buenas prácticas de construcción.

# Best Practices

Usar como fuente de apoyo pedagógico, subordinada a `.ai/` y a la documentación oficial en caso de conflicto.

# Common Mistakes

Adoptar recomendaciones genéricas del libro que contradigan una regla explícita del proyecto sin señalarlo (ver sección "Conflictos" en notas futuras si aparecen).

# Hermes Usage

Apoya la justificación de [[Maintainability over Cleverness]] y de las convenciones de nombres de [[Hermes Coding Standard]].
