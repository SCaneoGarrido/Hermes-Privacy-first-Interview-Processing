# Summary

Documentación oficial de ayuda de Obsidian, la aplicación en la que vive esta misma bóveda de conocimiento.

# Explanation

Fuente: https://obsidian.md/help/ (la URL `help.obsidian.md` redirige de forma permanente a esta, verificado 2026-07-24).

Obsidian es una aplicación de toma de notas que organiza información mediante notas interconectadas dentro de "vaults" personalizables. La ayuda cubre lo básico (crear un vault, crear la primera nota, enlazar notas) y funcionalidad extendida (plugins, temas, sincronización, publicación).

# Why it matters

Esta es la herramienta con la que el usuario navega y edita `hermes-vault-knowledge`; entender sus mecanismos de enlace (`[[nota]]`, alias, backlinks) es necesario para mantener la interconexión que exige la filosofía de esta bóveda.

# Best Practices

Usar aliases en el frontmatter (`aliases: [...]`) para que un mismo concepto sea alcanzable por varios nombres sin duplicar la nota (técnica usada extensamente en [[14 References]] y en los índices de sección).

# Common Mistakes

Crear notas nuevas sin verificar primero (vía búsqueda o backlinks) si el concepto ya tiene una nota existente, generando duplicados.

Aplicación base de toda esta bóveda de conocimiento; ver también [[MOC]] para el concepto de mapas de contenido específico de este método de organización.
