When generating code:

Always respect Clean Architecture.

Never introduce business logic inside controllers.

Never access SQLite directly from controllers.

Always create interfaces for infrastructure.

Do not introduce unnecessary dependencies.

Prefer standard library over third-party libraries.

Do not optimize prematurely.

Keep functions small.

Keep classes cohesive.

Use modern C++20.

Always explain architectural decisions when introducing a new dependency.

When unsure, ask instead of assuming.
